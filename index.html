🎲 4 Player Ludo Race

Kaise khelna hai?
1️⃣ Create Ludo Room dabao → Room ID milegi.
2️⃣ Room ID apne friends ko bhejo → woh neeche Join Room mein ID daalein.
3️⃣ 2–4 players ho jaane par creator ▶ Start Game dabaye.
4️⃣ Jiski turn ho woh 🎲 Roll Dice dabaye. Token ko finish tak pahunchane wala jeetega.
—
Room create ya join karo.

♟️ Online Chess — 2 Players

Kaise khelna hai?
1️⃣ Player 1 Create Chess Room dabaye → woh White hoga.
2️⃣ Room ID friend ko bhejo → friend ID daal kar Join Chess dabaye → woh Black hoga.
3️⃣ Chess board par pehle apna piece, phir jis square par chalna hai us square ko click karo.
4️⃣ White pehle chalega. Har move automatically doosre player ke board par aa jayega.
Chess room create ya join karo.
